# Casual Heat -- retired

The Casual Heat server (user `heat`, port 7757) was shut down for good on
2026-10-08; the user and its home directory were deleted. This directory is
kept as the record of how it was set up (the git history is the backup).
The port pair 7757/7758 now belongs to the Fun Modes server, see [../fun](../fun/README.md).
